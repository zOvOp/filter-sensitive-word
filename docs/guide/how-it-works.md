# 工作原理

## DFA（Trie 树）匹配

敏感词组织为 Trie 前缀树，从文本每个非干扰词位置出发沿树匹配：

- **时间复杂度**：O(n)，n 为文本长度
- **空间复杂度**：O(m × k)，m 为词库字符总量

## 干扰词处理

干扰词在匹配时被跳过，过滤时一并替换。文本按码点扫描，所以匹配区间前面的 emoji 不会把替换位置错开。词库里的干扰字符在入库时去掉；去掉后不足两个有效字符的条目不会变成单字。

```
输入：兼  职
路径：兼 → [跳过空格] → 职  →  命中「兼职」
```

## 最长匹配优先

多候选匹配时取最长词：

```
词库：["兼职", "兼职广告"]
输入：兼职广告 → 命中「兼职广告」（4 字）
```

## DFA + AI 组合建议

1. **DFA 先行**：本地、低延迟，拦截明确关键词
2. **AI 兜底**：DFA 未命中且需语义审核时再调大模型

```ts
if (!dfa.hasSensitive(text)) {
  const aiResult = await ai.detect(text);
}
```
